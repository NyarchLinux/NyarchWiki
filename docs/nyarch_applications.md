# Nyarch Applications

This article contains the list of Nyarch applications.
Some applications are only available for some Nyarch versions.

## Nyarch Tour

Nyarch Tour launches automatically after the first successful installation of Nyarch. Its purpose is to guide the user through Nyarch features and how to use its desktop.

### GNOME Version

- **App ID**: `moe.nyarchlinux.tour`
- **Launch Command**: `nyarchtour` (or `flatpak run moe.nyarchlinux.tour` when installed as a Flatpak)
- **GitHub Repository**: [https://github.com/NyarchLinux/NyarchTour](https://github.com/NyarchLinux/NyarchTour)
- **Language**: `Python`
- **Toolkit**: `GTK4 + Adwaita`

### KDE Version

- **App ID**: `moe.nyarchlinux.tourqt`
- **Launch Command**: `nyarchtourqt`
- **GitHub Repository**: [https://github.com/NyarchLinux/NyarchTourQT](https://github.com/NyarchLinux/NyarchTourQT)
- **Language**: `Python`
- **Toolkit**: `Qt + Kirigami (PySide6)`

## NekoPlay

NekoPlay is a high-performance video player built for watching anime, forked from [Cine](https://github.com/diegopvlk/Cine). It uses MPV as its playback backend while keeping a clean interface and adding a set of anime-specific features.

Features:

- **Clean interface**: A restrained, distraction-free design
- **MPV-based**: Strong playback performance and format support
- **Audio tracks and subtitles**: Freely switch and synchronize audio tracks and subtitles
- **Picture adjustments**: Brightness, contrast, scaling, aspect ratio, etc.
- **4K anime upscaling**: Use Anime4K to upscale 720p anime to 4K
- **90-second skip**: One-click intro skip (*most* anime intros are exactly 90 seconds long)

NekoPlay uses the same GTK app for both its GNOME and KDE versions; there is no separate Qt version.

### Application Info

- **App ID**: `moe.nyarchlinux.nekoplay`
- **Launch Command**: `nekoplay` (or `flatpak run moe.nyarchlinux.nekoplay` when installed as a Flatpak)
- **GitHub Repository**: [https://github.com/NyarchLinux/NekoPlay](https://github.com/NyarchLinux/NekoPlay)
- **Language**: `Python`
- **Toolkit**: `GTK4 + Adwaita`

## Nyarch Assistant

Nyarch Assistant is the official **AI catgirl** of Nyarch Linux. It supports Live2D / LivePNG avatars, TTS voices, terminal command execution, extensions, and local models. It is a fork of [Newelle](https://github.com/qwersyk/Newelle); full configuration and usage instructions are available on the [Nyarch Assistant](nyarchassistant.md) page.

Nyarch Assistant also uses the same GTK app for both its GNOME and KDE versions; there is no separate Qt version.

### Application Info

- **App ID**: `moe.nyarchlinux.assistant`
- **Launch Command**: `nyarchassistant` (or `flatpak run moe.nyarchlinux.assistant` when installed as a Flatpak)
- **GitHub Repository**: [https://github.com/NyarchLinux/NyarchAssistant](https://github.com/NyarchLinux/NyarchAssistant)
- **Language**: `Python`
- **Toolkit**: `GTK4 + Adwaita`
